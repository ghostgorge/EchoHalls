# 回响回廊 EchoHalls

一个**第一遍注定走不完**的迷宫。

光只照几格，步数上限只比最短解多一点点 —— 所以第一遍是侦察，
第二遍才是通关。你走过的地方会以暗色留在图上，那就是"回响"。

- 8 章 48 关，程序生成 + 求解器验收，从第 2 章起**盲目探路一次通关率压到 0~2%**
- 塞尔达谱系的机关：锁与钥匙、裂墙与炸弹、压板与石块闸门、火把与灯笼、
  按拍子起落的尖刺、踩一次就塌的地板、深坑、冰面、羽毛跳、钩爪
- 一命通关模式「无灯之夜」：不能撤销、地图记忆不保留、48 关连打，失手从头
- 28 项成就、存档、作弊台

设计细节与验收数据见 [`docs/回响回廊-关卡设计与验收方法.md`](docs/回响回廊-关卡设计与验收方法.md)。

## 运行

```
pip install pygame
python main.py
```

自测（含全部 48 关重新求解 + 机器人复验）：

```
python main.py --selftest
```

重烤关卡（改过 core/gen.py 之后）：

```
python tools/bake.py
```

## 打包 exe

双击 `build_exe.bat`，产物在 `dist\EchoHalls.exe`。

## 操作

| 键 | 作用 |
|---|---|
| 方向键 / WASD | 走一步 |
| 空格 | 原地等一步（尖刺按步数起落，等本身就是解法） |
| J | 羽毛跳（跨过前面一格坑或尖刺，2 步） |
| K | 钩爪（顺着铆点拉过深坑，2 步） |
| B | 炸弹（炸开裂墙） |
| L | 灯笼（点亮火把） |
| R | 回想（整张图闪一下，代价 3 步） |
| Z | 撤销（无灯之夜里没有） |
| N | 重来   Esc 菜单   H 说明 |
| 连按两下 Shift | 作弊台（UNLOCK / SKIP / SOLVE / REVEAL / STEPS / ACHV / RESET） |

按完 J/K/B/L 再按方向键选目标。

## 三条要点

1. **超步不丢人**。第一遍走不完是设计好的，地图会记下来。
2. **闸门要三件事同时满足才开**：压板全被石块压住、火把全点亮、拉杆全扳下。
   石块推错方向就再也推不回来。
3. **右侧面板写着这一关的"盲探一次通关率"**。看到 0% 就别指望现场蒙 —— 先探，再打。
